Core Algorithms

How the Optimization Works

Linear Programming (LP)

PuLP / CBC Solver

LP optimizes continuous logistics — maximizing priority score of allocated resources subject to transport weight constraints.

Maximize Z = Σ (priority_i × multiplier × x_i)
Subject to: Σ (weight_i × x_i) ≤ capacity_kg
            0 ≤ x_i ≤ min(requested_i, stock_i)

Knapsack Algorithm

Discrete Item Selection

Knapsack handles discrete resource selection — each item has a weight (kg) and a priority value. Best combination selected without exceeding capacity.

Knapsack Value = priority × category_multiplier
Knapsack Weight = weight_kg per unit
Capacity = vehicle max load (kg)
