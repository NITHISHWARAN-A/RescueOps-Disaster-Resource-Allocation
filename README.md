# RescueOps — Disaster Resource Allocation System

Optimized resource allocation in disaster management using **Linear Programming** and **Knapsack Algorithms**.

## Tech Stack
- Python 3.x, Flask
- PuLP (Linear Programming)
- SQLite3
- HTML/CSS/JS

## How to Run
```bash
pip install -r requirements.txt
python app.py
```
Then open `http://localhost:8080` in your browser.

## Features
- Urgency-based resource prioritization
- LP + Knapsack hybrid optimization
- Admin dashboard with dispatch logs
- Real-time inventory tracking
